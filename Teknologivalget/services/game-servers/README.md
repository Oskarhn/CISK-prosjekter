# Spillservere

## Aktive og driftsklare instanser

| Tjeneste | Port | Siste status |
|---|---:|---|
| Minecraft Optimalisert | `25567/tcp` | Online 2026-08-10 |
| Minecraft All The Mods 10 | `25568/tcp` | Online 2026-08-10 |
| Minecraft Cobbleverse | `25572/tcp` | Offline 2026-08-10 |
| Terraria Modded | `7779/tcp` | Online 2026-08-10 |

## Operativt ansvar

- kontrollere server- og klientversjon
- oppdatere modpack og dependencies
- ta backup av world/config før endring
- følge logs under første oppstart
- styre samtidige instanser etter tilgjengelige ressurser
- publisere korrekt status til brukerne
